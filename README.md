# PaperFocus

English | [中文](README.zh-CN.md)

PaperFocus is a macOS app for focused academic paper reading. It keeps a local paper library, opens PDFs in the app, and includes a focus timer. Optional paper summaries and translation use API keys that you enter in Settings; those keys are not stored in this repository.

Open `PaperFocus.xcodeproj` in Xcode to build and run it. The current project targets macOS 15.7 or later.

A license has not been attached yet and can be added later.
