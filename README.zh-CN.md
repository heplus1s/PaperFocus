# PaperFocus

[English](README.md) | 中文

PaperFocus 是一款面向专注阅读论文的 macOS 应用。它提供本地论文库、应用内 PDF 阅读，以及专注计时。论文摘要和翻译是可选功能，需在设置中自行填写接口密钥；本仓库不包含这些密钥。

在 Xcode 中打开 `PaperFocus.xcodeproj` 即可编译运行。当前工程的系统要求为 macOS 15.7 或更高版本。
